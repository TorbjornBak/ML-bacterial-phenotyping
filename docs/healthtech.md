# Getting started with the repository on DTU's Health Tech Cluster

## Logging in to the Health Tech cluster
To login type in the terminal:
```bash
ssh sxxxxxx@login.healthtech.dtu.dk
```

Then you have to write “yes” and type your DTU password, then authenticate with your Authenticator app on your phone. 
Now you should be logged in.

Here is DTU health tech’s guide to the cluster:
https://nexus.healthtech.dtu.dk/wiki/books/onboarding-information/page/beginners-guide-to-the-health-tech-cluster
